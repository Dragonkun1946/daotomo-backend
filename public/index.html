Tham gia server có mất phí không?

Hoàn toàn miễn phí. Chỉ cần Minecraft Java Edition và địa chỉ IP server ở trên — vào chơi ngay, không cần whitelist.

Server chạy phiên bản Minecraft nào?

Đảo Tò Mò hiện chạy trên phiên bản 1.21.4, hỗ trợ cả người chơi dùng bản gần nhất nhờ tương thích ngược.

Cửa hàng trong game hoạt động như thế nào?

Cửa hàng bán vật phẩm cosmetic và tiện ích hỗ trợ server vận hành — không bán lợi thế PvP hay sức mạnh, giữ đúng tinh thần fair-play.

Tôi có thể báo cáo vi phạm luật chơi ở đâu?

Mở ticket trong kênh #ho-tro trên Discord — đội ngũ admin trực gần như 24/7 và sẽ xử lý trong thời gian sớm nhất.
